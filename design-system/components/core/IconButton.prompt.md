**IconButton** — square, quiet icon affordance for toolbars and card actions; pass a Lucide SVG as the child and always set `label`.

```jsx
<IconButton label="More actions"><MoreIcon/></IconButton>
<IconButton variant="gold" label="Add"><PlusIcon/></IconButton>
```

Variants `ghost` (default) and `gold` (use sparingly — counts as the view's gold). Sizes `sm | md`.
